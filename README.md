# Portfolio Revamp — Luthfan Mursyidan

Personal portfolio website for Luthfan Mursyidan, a frontend and full-stack software engineer focused on building practical, production-ready web and mobile applications.

This portfolio is inspired by the visual direction of Taste Skill: bold typography, clean section-based layout, strong cards, minimal but confident copywriting, and a polished developer-product feel.

## Goal

The goal of this revamp is to make the portfolio feel less like a basic resume page and more like a strong personal landing page that sells engineering capability, product thinking, and real project experience.

The website should clearly communicate:

- Who I am
- What I build
- What technologies I use
- What projects I have worked on
- Why clients or companies should work with me
- How to contact me

## Design Direction

The design should use a modern developer/product style inspired by Taste Skill.

Key visual ideas:

- Big hero headline
- Short, confident subtitle
- Clear call-to-action buttons
- Dark/light mode support
- Strong card-based layout
- Minimal but premium-looking colors
- Clean spacing and typography
- Code/terminal-style elements where useful
- Project cards that feel like product showcase cards
- Smooth but subtle animation

The website should avoid looking like a generic template.

## 5. Case Study Format

Each major project should have a case study page or expanded section.

Template:

```txt
Problem
What issue was solved?

Solution
What was built?

My Role
What did I personally handle?

Tech Stack
What technologies were used?

Key Features
What are the important features?

Challenges
What was difficult?

Result
What was achieved?
```

Example:

```md
## Case Study: Echo Flow

### Problem

Users often record long voice notes but do not want to manually rewrite, summarize, or organize them.

### Solution

Echo Flow allows users to record audio, upload it, process it with AI, and receive transcript, summary, important points, and action items.

### My Role

I designed and developed the mobile app structure, backend API integration, authentication flow, upload logic, transcription status flow, and cloud processing architecture.

### Tech Stack

Flutter, Go, Gin, Firestore, Cloud Run, Cloud Tasks, Google Cloud Storage, Gemini API.

### Key Features

- Voice recording
- Audio upload
- AI transcription
- Background processing
- Guest login
- Google login
- Free/Pro limits
- Google Sheets export
- AdMob integration

### Challenges

- Handling async transcription status
- Managing audio upload limits
- Securing internal processing endpoints
- Supporting guest and Google authentication
- Creating a clean mobile experience for recording and previewing audio
```

## 8. Copywriting Tone

The writing should be:

- Clear
- Confident
- Direct
- Not too corporate
- Not too casual
- Focused on value and execution

Avoid:

```txt
I am passionate about coding and learning new technologies.
```

Better:

```txt
I build practical web and mobile applications with clean interfaces, reliable APIs, and production-ready workflows.
```

Avoid:

```txt
I know React, Next.js, Laravel, Flutter, Go...
```

Better:

```txt
I work across frontend, mobile, and backend layers — from responsive interfaces to API integration, cloud deployment, and AI-powered workflows.
```
